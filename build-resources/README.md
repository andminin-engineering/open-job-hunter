# Brand assets

`icon.png` is the source artwork for the Open Job Hunter application icon. `icon.ico` is the deterministic Windows conversion consumed by electron-builder.

The source artwork was generated on 2026-09-11 with OpenAI's image generation tool under human art direction. The brief requested a text-free, geometric target and upward career-path arrow using navy, blue, emerald and white, optimized for legibility at Windows icon sizes. The asset was selected and integrated as part of the project's AI-assisted delivery process.
