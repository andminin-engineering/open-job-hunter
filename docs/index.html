Open-source · MCP server · 100% local

Your job search, evaluated by AI —
on your machine, against your profile.

open-job-hunter discovers job offers from multiple boards and scores each one against your configurable profile using a local LLM. No cloud. No data leaving your computer.

⭐ View on GitHub Get started
🧩

Configurable profile

One profile.json drives everything. Describe your stack, seniority and targets — the tool works for anyone.

🤖

Local AI scoring

Every offer gets a 0–100 match score, apply decision, risks, strengths and a tailored pitch angle — via your own Ollama model.

🔎

Multi-source discovery

Pulls openings from Remotive, Greenhouse and Lever boards out of the box, plus generic URL ingestion.

📊

Application pipeline

A local database tracks each offer from discovered to offer, so nothing slips through the cracks.

📬

Scheduler + digests

Optionally run discovery on a schedule and get the top matches emailed to you.

🔒

Private by design

Evaluation runs on a local model. Your profile and pipeline never leave your machine.

How it works

Two interfaces — a standard MCP server for Claude and any MCP client, and an HTTP bridge for dashboards.

MCP client (Claude, etc.)  +  HTTP dashboard
↓
open-job-hunter — discovery · evaluation · pipeline
↓  prompt built from your profile.json
Ollama (local LLM)  — 🔒 your data stays here

Quickstart

Requires Node ≥ 20 and a running Ollama instance.

# 1. Clone & install
git clone https://github.com/andminin-engineering/open-job-hunter.git
cd open-job-hunter && npm install

# 2. Pull a local model
ollama pull qwen2.5:7b

# 3. Make the profile yours
cp config/profile.example.json config/profile.json
# ...edit config/profile.json with your background

# 4. Build & run
npm start
